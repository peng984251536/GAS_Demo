弓箭手小兵 · AnimGraph 结构图

召唤类 AI 小兵的动画蓝图节点拓扑。核心是把「决策」和「混合」分开：状态机只管 locomotion，所有一次性动作——拉弓、放箭、受击、击退——都通过 Slot 从外部注入。

AnimGraph 主图

姿态自上而下流入 Output Pose。两个 Slot 是 montage 的注入点，中间的分层节点决定上半身归谁管。

locomotion 状态机 姿态缓存 上半身注入点 上半身分层 全身覆盖

全身槽必须在分层之后。求值顺序是分层节点先算完整个角色，再由最外层的 Slot: FullBody 整体覆盖。如果把它挪进 Base Pose，因为 Blend Pose 0 的权重是 1.0，上半身永远由它决定——播死亡动画会变成「只死下半身」。

上半身槽的 Input 一定要接。空着不接的话，没播 montage 时该槽会落到参考姿势，上半身直接散架。图上那两条从 LocoPose 出发的线就是干这个的。

分界骨为什么是 spine_01

分支根决定分层节点从哪根骨头开始接管。它必须落在 spine_01 上，不能落在 pelvis 上。

如果分支根选成 pelvis，跑动时会变成下半身纹丝不动、整个人飘着射箭。这是最典型的一种「搭完了但看着不对」。

状态机：SM_ArcherLocomotion

四个状态，其中两个按需保留。先只做 Idle 和 Move 跑通，再往上加。

用 Any State → Dead 且 Dead 不设出口，死亡就是真正的终态——既不依赖 montage 播完，也不用额外加锁。UE 的 Any State 不会转换到「当前已经处于」的状态，所以 Dead 也不会自己重入。

InAir 可以砍掉。召唤兵如果不离地、不会被击飞，删掉这个状态能省一整条转换链。同理，如果 Idle/Move 在小兵互相推挤时来回抖，把进入阈值和退出阈值拉开（进 25 / 出 5）。

一次射击：GA 与 montage 的配合

拉弓和放箭放在同一个 montage 的两个 section 里，衔接发生在 montage 内部——这样蓄力时长才是可变的。

停在循环段上，任务永远不会完成。PlayMontageAndWait 只在 montage 正常播放结束时广播 OnCompleted。循环拉弓时它一直不回来，所以必须靠 MontageJumpToSection("Release") 走到收尾段，或者在被打断时显式结束技能——别写成「等这个任务完成再放箭」。
