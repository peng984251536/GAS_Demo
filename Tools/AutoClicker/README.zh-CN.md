# 游戏连点器 / 按键录制回放

Windows 桌面工具，包含定点连点和按键/鼠标宏录制回放。

## 宏录制

- `F7` 开始或结束录制；开始和结束都有系统提示音。
- 记录键盘按下/释放、鼠标左/右键按下/释放和点击坐标。
- 停止录制时保存为 exe 同目录的 `recording.json`，启动时自动载入。
- `F8` 回放；循环次数设为 0 表示无限循环，再按 `F8` 或按 `F12` 停止。
- 回放速度可设置为 `0.1×` 到 `5.0×`；`2.0×` 表示间隔减半，`0.5×` 表示间隔加倍。速度会保存在 `recording.json`。
- “清空记录”会删除本地录制文件。

## 连点

- `F6` 开始或停止鼠标左/右键连点，`F12` 紧急停止。
- 可设置点击间隔、按住时长和点击次数（0 表示无限）。
- 连点发生在鼠标当前位置。

游戏必须保持前台。部分游戏会拒绝 Windows 模拟输入；这类限制不能通过通用连点器绕过。工具会在 Windows 拒绝输入时显示错误码。
